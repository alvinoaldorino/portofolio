# Portofolio — Alvino Aldorino

Personal Portfolio Web Application with **Dark Cyber / Violet Aesthetic**, built for GitHub Pages deployment.

## 🚀 Live Demo
Website dapat diakses secara publik di:
`https://zaxkai.github.io/portofolio/` (setelah mengaktifkan GitHub Pages di settings repositori).

## 🛠️ Tech Stack
- **HTML5 & Semantic Markup**
- **Tailwind CSS** (Dark Mode, Custom Violet/Cyber palette)
- **Vanilla JavaScript** (Smooth scrolling, dynamic mobile navigation, mail client trigger)
- **Pixel Art Mascot** (Standalone inline SVG 8-bit companion)
- **Lucide Icons & Vector SVGs**

## ⚙️ How to Deploy to GitHub Pages
1. Masuk ke halaman repositori di GitHub: `https://github.com/zaxkai/portofolio`.
2. Klik tab **Settings** -> **Pages**.
3. Di bagian **Build and deployment > Source**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`.
5. Klik **Save**. Website Anda akan live dalam beberapa detik!
